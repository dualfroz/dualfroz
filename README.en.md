> _Hi, I'm Michał. I'm 18 and I'm from Kraków. I've been building all kinds of software projects regularly since 2020. For most of that time I focused on backend logic, but lately I've been shifting more towards design and UI/UX, fields that are far more resistant to the impact of LLMs. I believe creativity and ideas are two things that will stay untouched forever._
>
> _I contribute to all kinds of open source projects often and actively. I like helping and supporting communities wherever I can. I know my work isn't always perfect, so I always review it carefully, making sure that only the highest-quality additions and fixes land in projects used by thousands or even millions of people._
>
> _I have over 6 years of programming experience. In that time I've written **over 3,000,000** lines of code across **200+** projects. Altogether I've contributed to **40** open source repositories with a combined **250,000+** stars on GitHub._
>
> _Outside of programming I'm interested in a lot of things: art, history, linguistics, mathematics, chess, music... the list goes on._

> **Now:** I've recently been working on finishing the first version of Flaem, a hosting panel. The project is written in several languages (TypeScript, Rust, Elixir, Golang, plus microservices in Java, Python and C) and adds up to almost a million lines of code. I'm planning the first release of Flaem for around October/November 2026.
